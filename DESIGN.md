# Visual direction: Salvage Bay

Cyberpunk scavenger's workbench: dark instrument panels, labeled parts drawers, small status lights, and acid-lime accents. Component photos are the visual focus.

This is the proposed starting direction based on the user's reference screenshot and request for a rusty metal panel; final visual choices remain reviewable.

## Palette

| Role | Starting color |
| --- | --- |
| Base | Charcoal #171C1B |
| Working panels | Muted olive-gray |
| Body text | Warm off-white |
| Primary action / selection | Acid lime #C6F36B |
| Needs identification | Amber #FFB454 |

Choose distinct warning and error treatments; labels and icons must carry meaning alongside color. Verify contrast during implementation.

## Rusted metal casing

Place a restrained rusty metal surface on the outer bench frame, a navigation rail, or a header nameplate. Explore worn paint, oxidized seams, inset screws, and a stamped BENCHMATE plate. These are design options, not required decorations on every surface.

Keep the rust outside the main reading surfaces. Inventory labels, datasheet excerpts, and assembly instructions sit on clean dark inset panels. The intended effect is a maintained instrument installed in a weathered enclosure.

## Interface details

- Readable sans-serif text for instructions; monospace for part numbers, dimensions, pin labels, and salvage IDs.
- Salvage tags show photo, identity status, condition, source, and physical location.
- Subtle workspace grid; modest glow only during active scanning or processing.
- Make photo intake and the scavenging assistant prominent, with an obvious route into identification review and inventory.
- Keep inventory and project progress visible outside the conversation.
- Use Stash, Build ideas, and Projects as destinations. Identification lives inside the stash item form: photo -> Identify -> review populated metadata -> Save.
- On mobile, prioritize capturing parts and confirming identities. Larger screens can accommodate inventory inspection and documented build steps side by side.
- Use clear actions such as Add to stash, Confirm identity, Reserve parts, and Return to stash.
- Do not let decorative distress, terminal styling, or animation obscure electrical details or state changes.
